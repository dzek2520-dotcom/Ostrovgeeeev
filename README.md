# 🌋 ISLAND OF CHAOS (Остров Хаоса)

Браузерная мультиплеерная игра на выживание, вид сверху, 2D. Вы и до 11 других игроков оказываетесь на маленьком
острове 64×64, где постоянно происходят **случайные катаклизмы** — их в каталоге **1400+**. Продержитесь дольше всех.

- **Клиент:** чистый HTML5 Canvas + ES-модули, без фреймворков, без внешних ассетов и CDN (графика и звук синтезируются в коде).
- **Сервер:** Node.js + Express + WebSocket (`ws`), авторитетная симуляция 20 Гц.
- **Деплой:** один Web Service на Render.com (HTTP и WSS на одном порту).

## Правила

Остров генерируется по seed (пляж, лес, скалы, озеро, болото, вулкан с лавой, пещеры). Тайлы меняются:
горят, затопляются, замерзают, трескаются, заражаются радиацией и токсинами.

**Показатели:** здоровье ❤️, сытость 🍖, жажда 💧, выносливость ⚡, рассудок 🧠, температура тела 🌡️.
**Ресурсы:** дерево, камень, еда, вода, металл, ткань, топливо, лекарства, артефакты (+ рыба, желе).

**Защита.** У каждого катаклизма есть *теги угроз* и *теги защиты* (показаны в баннере, с иконками того, что спасает).
Защищают: экипировка в рюкзаке (куртка, броня, противогаз, плот, артефакт), постройки рядом (укрытие, костёр,
бункер, громоотвод, дамба) и местность (пещера защищает от погоды, вода — от огня и взрывов).

**Режимы** (настраивает хост в лобби):
- **PvP** — игроки могут бить друг друга и красть. Без PvP — чистая кооперация (лечить, отдавать, строить вместе).
- **Хаос** — катаклизмы идут почти без пауз, чаще внезапные и комбо.

**Победа.** Если игроков больше одного — побеждает последний выживший; иначе раунд идёт, пока жив хоть кто-то.
В итогах: время выживания, добытые ресурсы, пережитые катаклизмы, помощь другим, убийства. Есть кнопка «Реванш».

## Запуск локально

Нужен Node.js 18+.

```bash
npm install && npm run dev      # режим разработки (перезапуск при изменениях)
# или
npm install && npm start
```

Откройте http://localhost:3000 в двух окнах браузера: в одном «Создать комнату», в другом введите код.
С телефона в одной Wi-Fi сети откройте `http://<IP-компьютера>:3000`.

Другие команды:

```bash
npm run check:cataclysms   # проверка каталога: ≥1000, уникальность, поля, статистика
npm test                   # тесты логики, каталога и симуляции
```

## Структура проекта

Все файлы лежат в одной папке (без подпапок):

```

rooms.js             комнаты, лобби, переподключение, чат, rate limit

world.js             генерация острова по seed, операции над тайлами

director.js          «Режиссёр катаклизмов»
mobs.js              существа и их ИИ
archetypes.js        128 вручную написанных катаклизмов
modifiers.js         таблицы: зоны, модификаторы, масштабы, побочные эффекты
generator.js         процедурный генератор (1400+ записей)
fx.js  zones.js  catalog.js     конструкторы эффектов, зоны, кэш каталога
rng.js  validate.js  rateLimit.js   утилиты
index.html  style.css            клиент: разметка и оформление
shared.js main.js net.js input.js render.js ui.js audio.js i18n.js   клиент: модули
check-cataclysms.js  sim.test.js  cataclysms.test.js   проверка каталога и тесты
package.json  render.yaml  .env.example  .gitignore  LICENSE  README.md  PROTOCOL.md
```

> Серверный код наружу не раздаётся: `server.js` отдаёт браузеру только `index.html`, `style.css` и клиентские `*.js`.

## Как устроены катаклизмы

```
КАТАКЛИЗМ = архетип × модификатор(стихия) × масштаб × зона × побочный эффект × длительность
```

1. **Архетипы** (`archetypes.js`) — 128 катаклизмов вручную: природные, биологические, космические,
   абсурдные, техногенные, социальные. У каждого своя механика.
2. **Генератор** (`generator.js`) детерминированно (фиксированный seed) порождает по 10 вариантов на архетип.
   Модификатор добавляет эффекты и теги (огненный → поджигает, ядовитый → отравляет, призрачный → призраки…),
   масштаб умножает интенсивность и меняет тяжесть, зона задаёт где это происходит, побочный эффект — «хвост».
   Название склеивается с согласованием рода: *«Мощное электрическое торнадо на юго-востоке с мерцающим светом»*.
3. **Режиссёр** (`director.js`) выбирает следующий катаклизм: тяжесть растёт со временем, не повторяет недавние,
   учитывает состояние игроков, иногда запускает комбо и «внезапные» без предупреждения.

Запись катаклизма: `id, name, description, tags, counterTags, severity, warningTime, duration, cooldown, zone,
effects[], visuals, sound, weight, minPlayers, canCombineWith[]`.

### Как добавить новый катаклизм

Откройте `archetypes.js` и добавьте вызов `A(...)` перед концом файла:

```js
A('sky_whales', 'Небесные киты', 'p', 'magic', 3,
  'Над островом проплывают киты и роняют воду и рыбу.',
  { t: [], c: [], z: 'WIDE', dur: 30, s: 'chime',
    fx: [lt('water', 2, 2), lt('fish', 1, 4), dr('sanity', 0.5)],
    v: vis('#9ad0ff', 0.1, 0, 'bubbles') });
```

Параметры: `id`, название, род (`m/f/n/p` — для согласования прилагательных), категория, тяжесть 1–10,
описание и опции (`t` угрозы, `c` защита, `z` группа зон, `fx` эффекты, `v` визуал, `s` звук, `min` игроков, `w` вес).
Эффекты — функции из `fx.js` (`dmg, st, dr, tl, sp, lt, ph, strike, sd, steal, tele, swap, heal, hunt`).
Дальше генератор сам создаст ~10 вариантов. Новые модификаторы, зоны и побочные эффекты добавляются
в `modifiers.js`. Проверьте результат: `npm run check:cataclysms`.

## Деплой: GitHub + Render

### 1. GitHub

```bash
cd island-of-chaos
git init
git add .
git commit -m "ISLAND OF CHAOS: первая версия"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/island-of-chaos.git
git push -u origin main
```

(Репозиторий `island-of-chaos` предварительно создайте на github.com → New repository, пустой.)

### 2. Render

1. https://render.com → **New → Blueprint**, выберите репозиторий — Render прочитает `render.yaml`.
   Либо **New → Web Service**: Runtime `Node`, Build Command `npm install`, Start Command `npm start`,
   Health Check Path `/health`, Plan `Free`.
2. Дождитесь статуса *Live*.

### 3. Проверка

- Откройте `https://<имя>.onrender.com/health` — должно быть `{"ok":true,...}`.
- Откройте `https://<имя>.onrender.com/` — игра. Клиент сам подключается по `wss://`.

> **Бесплатный план Render засыпает** после ~15 минут без запросов, первый запрос будит сервис до ~60 секунд.
> Поэтому клиент показывает экран «Подключение к серверу…» и повторяет попытки примерно 2 минуты.
> Состояние комнат хранится в памяти: при перезапуске или засыпании активные игры сбрасываются.

## Сетевая модель и защита

- Авторитетный сервер: клиент шлёт только ввод; движение, урон, катаклизмы, крафт и инвентарь считает сервер.
- Тик 20 Гц; клиент предсказывает своё движение общей функцией `moveStep` и сверяется по `ack`, чужих интерполирует.
- Ограничение «кредита времени» на движение (нет спидхака), валидация и санитизация всех полей,
  «ведро токенов» на сообщения и чат, ограничение размера пакета.
- Переподключение: токен хранится в `localStorage`; место в игре держится 75 секунд (в лобби — 12).
